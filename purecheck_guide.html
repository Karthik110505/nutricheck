De-obfuscating Food & Skin Care Ingredients

Scan food packaging and cosmetics lists to instantly decode harmful chemical additives, hidden elements, and deceptive labeling with personalized AI models.

What is PureCheck AI?

Decoding complex chemical terms into everyday English and alerting users to safety grade classifications based on individual health objectives.

Ingredient De-obfuscation

Translates complex industry-standard labeling and chemical codes. It unmasks deceptive naming structures such as converting "Refined Vegetable Oil" into its likely real name like "Palm / Soy Oil", or "Hydrolyzed Protein" into hidden flavor enhancer "MSG".

Personalized Safety Profiles

Evaluates safety grading strictly mapped to your health goals: Gut Health focus, Diabetic-friendly audit, Cardiovascular/Heart health parameters, Cruelty-free/Vegan standards, and Cosmetic ingredient audits.

AI Inspector Chatbot

Allows natural language follow-up conversations on scanned items. Users can ask queries like "Is this safe for kids?", "Why does it trigger high heart risks?", or "Which specific oil was used here?" for granular explanations.

Why Use PureCheck?

Addressing transparency gaps in the food processing and cosmetics retail industries.

The Food Deception Problem

Most packaged products sold in retail stores contain highly processed emulsifiers, thickeners, hidden palm oil, or synthetic preservatives designed to extend shelf life rather than sustain health. Food regulations allow corporations to list complex names like "Carrageenan" or "E120" which mask potential inflammation triggers and animal-derived sources.

PureCheck AI acts as your private biochemist inside the store, bypassing marketing labels and displaying pure safety audits in real time.

The Operational Architecture Flow

How data navigates from camera shutter to the AI LLM and parses back into structured segments.

Core Technology Stack

Constructed with high-performance native libraries to ensure fast image processing and seamless user navigation.

UI Framework

Jetpack Compose & Material 3

Modern declarative native UI elements. Leverages edge-to-edge layouts, smooth animations, and rich dark palettes conforming to material styling systems.

Camera

Android Jetpack CameraX

Manages hardware sensors, viewfinder previews, flash control, and captures raw images at optimal resolution without blocking main UI threads.

Model API

Gemini, Groq & DeepSeek V3

Provides deep food/cosmetic ingredient analysis. Connects directly to Gemini 2.0, Groq Llama, and DeepSeek APIs to parse and grade chemical compounds.

On-Device OCR

Google ML Kit Text Recognition

Performs blazing fast local optical character recognition (OCR) on-device. Minimizes network payload sizes to eliminate API timeouts during image scans.

Routing

Google Navigation 3

State-of-the-art navigation stack for Compose. Employs type-safe navigation keys to push screens, passing result payloads seamlessly.

Networking

OkHttpClient & Retrofit

Robust networking client featuring custom connection timeouts (30 seconds) and retry configurations to handle unstable network situations during scans.

Storage

Gson & SharedPreferences

Serialized cache memory structures to persist previous product scan history records. Maintains user health profile switches locally.

Language

Kotlin Coroutines

Asynchronous runtime execution blocks. Handles IO operations (image encoding, API requests, file access) off the main thread.

Data Persistence Layer (data/)

Leverages Gson to serialize history objects and store them inside Android SharedPreferences. This guarantees offline access to previous ingredient audits.

UI Components Layer (ui/)

Constructed around Jetpack Compose components. Features modular view models displaying dashboards, real-time overlays, toggling selectors, and interactive chat text bubbles.

Utility Network Wrapper (utils/)

Direct integration block referencing API endpoints. Generates system prompts based on current active profile switches and maps structural JSON keys returned by the models.

Navigation Control (Navigation.kt)

Uses modern Navigation 3 Compose API keys representing screens. Handles lifecycle transitions (e.g. popping the camera screen after capturing an image to load results directly).

File-by-File Technical Specification

Granular operational explanations mapping the class structure and file contents inside the codebase.

AndroidManifest.xml Config

Declares application configurations, theme styles (Theme.PureCheck), activity declarations (MainActivity), and maps system-level permissions required for app functionality, specifically CAMERA (for live scanning viewfinders) and INTERNET (for remote model API network requests).

MainActivity.kt Entry

The standard launcher activity of the Android application. Sets up Compose UI content, calls enableEdgeToEdge() to draw elements behind system status bars, and anchors the theme container PureCheckTheme to launch MainNavigation() routing.

Navigation.kt Router

Manages the application view routes. Uses Navigation 3's entryProvider structure to compile state transitions across main pages, passing analyzed ingredient JSON payloads from camera viewfinders to detail results sheets.

NavigationKeys.kt Router

Specifies the type-safe destination tokens for navigation routes. Defines destinations like Main, Scanner, Settings, Author, and Result (which stores the serialized JSON analysis data payload).

PureCheckPreferences.kt Data

Coordinates persistence operations using local SharedPreferences. Declares data models UserProfile and HistoryItem, caching user constraints (Vegan, Diabetic) and serializing up to 50 previous scan logs to local memory.

Theme.kt Theme

Initializes the Material 3 themes configuration. Incorporates support for Android dynamic colors on compatible device variants, maps dark/light color schemes, and sets custom screen typography styles.

Color.kt Theme

Defines the color tokens used throughout the application, such as dark-slate card fills, slate backgrounds, warning highlights, and custom emerald green accents.

Type.kt Theme

Defines the typography tokens mapped to standard material typographic styles, mapping custom letter spacing and line heights.

AuthorScreen.kt UI

Renders student credentials. Incorporates customized detail displays (Roll Number: R210111, contact coordinates, department data) and a circular avatar profile picture.

MainScreen.kt UI

The home dashboard. Lists previous scan histories, lets users edit search titles or remove history listings, displays welcome alerts, and prompts warning cards if API keys aren't set.

ScannerScreen.kt UI

Integrates CameraX and Google ML Kit. Launches viewfinders, captures raw snapshots, executes local OCR to extract text on-device, and coordinates async API requests via GeminiClient.

ResultScreen.kt UI

Displays audit reports. Compiles letter safety grades (A-F), scores health metrics, parses obfuscated components, outlines swaps, and runs conversational chat view dialogs.

SettingsScreen.kt UI

Configures custom profile limits. Provides input forms to configure Google Gemini, Groq, and DeepSeek API credentials and toggles target health profile filters.

GeminiClient.kt Network

Interfaces with the AI endpoints. Sends multimodal image payloads to Gemini, or raw text payloads extracted by ML Kit to Groq/DeepSeek chat completion endpoints, returning structured JSON.
